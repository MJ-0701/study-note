Datadog Student Pack 기준

study-note 모니터링 셋업 가이드

실제 사용자가 Datadog, Vercel, Azure 콘솔에서 무엇을 설정해야 하는지 따라가기 위한 문서입니다.

현재 구조

Frontend

Vercel production SPA, study-note.910701.xyz

Backend

Azure Container Apps, study-note-api

Datadog

US5 student org, RUM + Azure integration 우선

분석 목표

퍼널, 리텐션, 장애/성능 감지

중요

Datadog API Key를 Vercel의 VITE_ 변수나 브라우저 코드에 넣지 않습니다.

RUM의 applicationId, clientToken은 브라우저용 공개 값입니다.

Vercel Production 환경변수

VITE_DD_APPLICATION_ID=<Datadog RUM application id>
VITE_DD_CLIENT_TOKEN=<Datadog RUM client token>
VITE_DD_SITE=us5.datadoghq.com
VITE_DD_SERVICE=study-note-web
VITE_DD_ENV=production
VITE_DD_SESSION_REPLAY_SAMPLE_RATE=0
VITE_DD_TRACK_USER_INTERACTIONS=false

Azure Backend APM 환경변수

백엔드는 Datadog에서 study-note-api 서비스로 생성되게 합니다. API key와 Application key는 코드와 GitHub에 넣지 않고 Azure Container App secret으로만 보관합니다. 

DD_API_KEY=secretref:dd-api-key
DD_APP_KEY=secretref:dd-app-key
DD_SERVICE=study-note-api
DD_ENV=production
DD_VERSION=<be tag version>
DD_SITE=us5.datadoghq.com
DD_TRACE_ENABLED=true
DD_LOGS_ENABLED=true
DD_LOGS_INJECTION=true
DD_SOURCE=nodejs

사용자 콘솔 작업

Datadog API key와 Application key 생성 후 Azure Container Apps의 study-note-api에 secret으로 저장합니다.

배포 후 확인

Datadog APM -> Services와 /admin.html 운영 지표 패널에서 API latency, 5xx, logs를 확인합니다.

az containerapp secret set \
  --name study-note-api \
  --resource-group study-note-be-rg \
  --secrets \
    dd-api-key=<DATADOG_API_KEY> \
    dd-app-key=<DATADOG_APPLICATION_KEY>

az containerapp update \
  --name study-note-api \
  --resource-group study-note-be-rg \
  --set-env-vars \
    DD_API_KEY=secretref:dd-api-key \
    DD_APP_KEY=secretref:dd-app-key \
    DD_SITE=us5.datadoghq.com

개인정보 원칙

보내도 되는 값: role, env, service, version, status_code, file_size_bucket, page_count_bucket.

보내면 안 되는 값: 이름, 학번, 이메일, PDF 파일명, 노트 본문, annotation payload, persona prompt/response, session cookie, API key.

Hackle 판단

공개 가격 기준으로 GitHub Student Pack 같은 학생 무료 플랜은 확인되지 않았습니다. 현재는 이미 활성화된 Datadog 학생팩으로 먼저 RUM/Product Analytics를 사용합니다.
