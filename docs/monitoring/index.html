Grafana + Prometheus 기준

study-note 모니터링 셋업 가이드

공개 운영 안내는 Grafana 대시보드 하나로 통일합니다. Prometheus가 backend /api/metrics를 수집하고, admin SPA는 Grafana 링크만 활성화합니다.

현재 구조

Frontend

Vercel production SPA, study-note.910701.xyz

Backend

Azure Container Apps, study-note-api

Prometheus

study-note-prometheus, internal ingress, 15s scrape

Grafana

study-note-grafana, anonymous viewer read-only

Datadog 공개 안내 제외

Datadog dashboard와 /api/v1/admin/ops-dashboard는 개발자 참고용 legacy snapshot으로만 남깁니다.

2026-05-28 기준 ACA serverless-init workloadmeta 문제로 backend APM 지표가 안정적이지 않습니다.

Vercel Production 환경변수

VITE_GRAFANA_URL은 선택입니다. 미설정 시 admin SPA가 production Grafana URL로 fallback합니다. 

VITE_GRAFANA_URL=https://study-note-grafana.bluesea-474361c6.koreacentral.azurecontainerapps.io/d/study-note-ops
VITE_GRAFANA_LABEL=Grafana 운영 대시보드

운영 화면 확인

  1. https://study-note.910701.xyz 접속 후 master/admin 계정으로 로그인합니다.
  2. /admin.html#ops를 엽니다.
  3. Grafana + Prometheus 기준 문구를 확인합니다.
  4. Datadog 조회 비활성화 버튼이 disabled 상태인지 확인합니다.
  5. Grafana 운영 대시보드 열기로 Grafana를 엽니다.

처음 볼 지표

영역지표이유
API호출량, 5xx, route별 req/s배포 후 트래픽과 오류 확인
Latencyp50, p95, p99느린 요청과 체감 성능 확인
Sync필기 자동저장 success/failure/stale학습 데이터 저장 안정성 확인
RuntimeNode.js heap, event loop lag메모리/런타임 압박 확인
CostACA Grafana/Prometheus scale학생 크레딧 한도 관리

Grafana 부팅/종료

GRAFANA_PASSWORD='<strong-password>' pnpm run infra:monitoring:up
pnpm run infra:monitoring:down

항상 켜두면 ACA 비용이 생길 수 있습니다. 크레딧 보호가 필요하면 종료 스크립트로 Grafana/Prometheus를 scale-to-zero 합니다.

개인정보 원칙

보내도 되는 값: role, env, service, version, status_code, file_size_bucket, page_count_bucket, route, outcome.

보내면 안 되는 값: 이름, 학번, 이메일, PDF 파일명, 노트 본문, annotation payload, persona prompt/response, session cookie, API key.
