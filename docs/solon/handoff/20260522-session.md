### 3.1 S1 구현 (BE controllers + R2 storage)

목표: `UserNotesController` + `PdfAnnotationsController` 두 모듈. 영속화는 기존
`S3StorageService` 의 `putObject`/`getObject` 재사용 (R2 endpoint).

- 모듈 위치: `apps/api/src/user-notes/`, `apps/api/src/pdf-annotations/`.
- 라우트 (`/v1/...` prefix):
  - 개별: `GET/PUT /v1/notes/week/{weekId}`, `GET/PUT /v1/pdf-annotations/{materialId}`.
  - bulk (opt-in): `GET /v1/notes`, `GET /v1/pdf-annotations` (prefix listing + pagination).
- R2 key 패턴:
  - `notes/{userId}/week-{weekId}.json` (JSON `{ body, updatedAt }`).
  - `annotations/{userId}/material-{materialId}.json` (JSON `{ payload, updatedAt }`).
- 인증: 기존 cookie session 미들웨어 재사용.
- payload size cap: 256KB / route (server-side 413).
- last-write-wins (updatedAt) — PUT 시 R2 overwrite.
