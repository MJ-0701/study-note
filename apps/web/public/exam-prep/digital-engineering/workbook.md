## 힌트 PDF

### 7장 회로의 논리식

왼쪽 회로:
- 위 AND: `HD`
- 아래 AND: `DK`
- OR 출력: `F = HD + DK`
- 인수분해: `F = D(H + K)`

오른쪽 회로:
- OR 출력: `H + K`
- AND 출력: `F = D(H + K)`

결론: 두 회로는 같은 논리식 `F = D(H + K)`를 갖는다.

### 6장 카르노맵 간소화

힌트 PDF 3쪽은 식을 카르노맵으로 옮긴 뒤 묶는 문제다.

풀이 순서:
1. 각 곱항을 minterm 번호로 바꾼다.
2. 3변수 카르노맵은 열을 `yz = 00, 01, 11, 10` 순서로 놓는다.
3. 1이 들어간 칸을 최대 크기로 묶는다.
4. 묶음에서 변하지 않는 변수만 남긴다.

시험장에서 식의 보수 표시를 잘못 읽는 실수가 제일 크다. 원본을 보면서 `x'`, `y'`, `z'`를 먼저 minterm 번호로 써두고 시작한다.

### 7장 가산기

외울 식:
- 반가산기: `S = A xor B`, `C = AB`
- 전가산기: `S = A xor B xor Cin`
- 전가산기 자리올림: `Cout = AB + ACin + BCin`

### 7장 비교기

1비트 비교:
- `A > B = AB'`
- `A = B = AB + A'B'`
- `A < B = A'B`

다중 비트 비교는 최상위 비트부터 본다.

### 8장 NOR SR 래치 진리표

| S | R | Q 다음 상태 |
|---:|---:|---|
| 0 | 0 | 유지 |
| 0 | 1 | 0 |
| 1 | 0 | 1 |
| 1 | 1 | 부정 |

### NOR SR 래치 파형

조건: 초기 `Q = 0`, 게이트 지연 없음.

- `S = 1, R = 0`이면 Set이므로 `Q = 1`
- `S = 0, R = 1`이면 Reset이므로 `Q = 0`
- `S = 0, R = 0`이면 이전 상태 유지

힌트 PDF 파형 기준:
- 1~2 구간: S 펄스 때문에 `Q = 1`
- 2~3 구간: 유지, `Q = 1`
- 3~4 구간: R 펄스 때문에 `Q = 0`
- 4~5 구간: 유지, `Q = 0`
- 5~6 구간: S 펄스 때문에 `Q = 1`
- 6~7 구간: 유지, `Q = 1`
- 7~8 구간: R 펄스 때문에 `Q = 0`
- 8~9 구간: 유지, `Q = 0`

### 6장 NAND 회로 출력 간소화

힌트 PDF 마지막 회로:
- B가 먼저 반전되어 `B'`가 된다.
- 첫 NAND 출력: `(AB')'`
- 마지막 NAND 출력: `X = ((AB')'B')'`
- 드모르간 적용: `X = A + B`

## 퀴즈 PDF

### 진리표 간소화 1

진리표:

| A | B | Y |
|---:|---:|---:|
| 0 | 0 | 1 |
| 0 | 1 | 0 |
| 1 | 0 | 1 |
| 1 | 1 | 1 |

1이 되는 항: `m0, m2, m3`

카르노맵으로 묶으면:
- `A = 1`인 묶음
- `B = 0`인 묶음

답: `Y = A + B'`

### 진리표 간소화 2

퀴즈 PDF 3쪽 답:

`X = A' + B'`

해석:
- `A = 0`인 행 전체 묶음
- `B = 0`인 열 묶음

### 선택적 카르노맵 간소화

퀴즈 PDF 4쪽 답:

`F = A'D' + A'C + B'D'`

핵심:
- `x` 무관항은 큰 묶음을 만들 수 있으면 사용한다.
- 가장자리 래핑으로 모서리끼리 묶을 수 있다.

### 조합회로 명칭

퀴즈 PDF 5쪽 회로:

답: 4비트 병렬 가산기/감산기

이유:
- 각 비트에 전가산기 FA가 있다.
- B 입력이 XOR를 통과한다.
- 제어 입력 `S`가 `0`이면 덧셈, `1`이면 B를 반전하고 `C0 = 1`이 되어 2의 보수 감산이 된다.

### NOR 게이트 SR 플립플롭 진리표

| S | R | Q 다음 상태 |
|---:|---:|---|
| 0 | 0 | 유지 |
| 0 | 1 | Reset, 0 |
| 1 | 0 | Set, 1 |
| 1 | 1 | 부정/금지 |

## 시험 직전 10분 체크

- 카르노맵 열 순서 `00, 01, 11, 10`을 실수하지 않는다.
- 무관항은 무조건 쓰는 것이 아니라 도움이 될 때만 쓴다.
- NOR SR 래치에서 `S=1,R=1`은 금지다.
- NAND SR 래치는 입력이 active-low라 금지 입력이 `S'=0,R'=0`이다.
- 전가산기 `Cout = AB + ACin + BCin`을 바로 쓴다.
- JK `11`은 toggle, T `1`도 toggle이다.
- 회로식은 게이트마다 중간 출력을 먼저 적고 간소화한다.

## 우선순위

1. 힌트 PDF와 퀴즈 PDF의 유형을 먼저 푼다.
2. 6장은 카르노맵, 무관항, NAND/NOR 변환, XOR/XNOR를 집중한다.
3. 7장은 가산기, 비교기, 디코더/인코더, MUX/DEMUX, 가산기/감산기 명칭을 외운다.
4. 8장은 SR 래치, SR/D/JK/T 플립플롭 진리표와 특성식을 외운다.

## 6장 논리식의 간소화

카르노맵 기본:
- 인접 칸은 변수 하나만 달라야 한다.
- 묶음 크기는 1, 2, 4, 8처럼 2의 거듭제곱이다.
- 가능한 크게 묶고, 묶음 수는 적게 만든다.
- 가장자리끼리도 인접한다. 좌우 끝, 위아래 끝을 이어서 생각한다.
- 무관항 `X`는 간소화에 도움이 되면 1처럼 묶고, 도움이 안 되면 버린다.
- 4변수 카르노맵 순서는 보통 `00, 01, 11, 10`의 Gray code 순서를 쓴다.

대표식:
- XOR: `A xor B = A'B + AB'`
- XNOR: `A xnor B = AB + A'B'`
- 드모르간: `(AB)' = A' + B'`, `(A + B)' = A'B'`

NAND/NOR 변환:
- NAND는 AND 뒤 NOT이다. SOP 형태를 NAND-NAND 구조로 바꾸기 좋다.
- NOR는 OR 뒤 NOT이다. POS 형태를 NOR-NOR 구조로 바꾸기 좋다.
- 모든 논리 게이트는 NAND만으로도, NOR만으로도 구현 가능하다.

## 7장 조합논리회로

가산기:
- 반가산기: `S = A xor B`, `C = AB`
- 전가산기: `S = A xor B xor Cin`
- 전가산기 자리올림: `Cout = AB + (A xor B)Cin = AB + ACin + BCin`
- 병렬 가산기는 여러 전가산기를 연결한다.
- 자리올림 예측 가산기에서는 보통 `G = AB`, `P = A xor B` 또는 교재 정의에 따라 `P = A + B`를 쓰고 `Cnext = G + P Cin` 형태로 본다.

비교기:
- 1비트 `A > B`: `AB'`
- 1비트 `A = B`: `AB + A'B'`, 즉 XNOR
- 1비트 `A < B`: `A'B`
- 여러 비트 비교는 최상위 비트부터 우선 비교한다.

디코더/인코더:
- 디코더: n개의 입력을 최대 `2^n`개의 출력 중 하나로 변환한다.
- 인코더: 여러 입력 중 활성 입력을 이진 코드로 변환한다.
- 우선순위 인코더는 여러 입력이 동시에 1이어도 높은 우선순위 입력을 출력한다.

MUX/DEMUX:
- MUX: 여러 입력 중 하나를 선택해 하나의 출력으로 보낸다.
- DEMUX: 하나의 입력을 선택선에 따라 여러 출력 중 하나로 보낸다.
- `2^n`개 입력 MUX에는 n개의 선택선이 필요하다.

가산기/감산기:
- 4비트 병렬 가산기/감산기는 XOR로 B 입력을 선택적으로 반전하고, `C0 = S`를 넣는다.
- `S = 0`이면 덧셈, `S = 1`이면 2의 보수 방식 감산이 된다.

## 8장 플립플롭

래치와 플립플롭:
- 래치는 입력 레벨에 민감하다.
- 플립플롭은 클록 에지에 민감하다.
- 게이티드 래치는 Enable/Clock이 허용될 때만 입력이 반영된다.
- 에지 트리거 플립플롭은 상승/하강 에지 순간에만 상태가 바뀐다.

NOR SR 래치:

| S | R | Q 다음 상태 |
|---:|---:|---|
| 0 | 0 | 유지 |
| 0 | 1 | 0, Reset |
| 1 | 0 | 1, Set |
| 1 | 1 | 부정/금지 |

NAND SR 래치:

| S' | R' | Q 다음 상태 |
|---:|---:|---|
| 1 | 1 | 유지 |
| 0 | 1 | 1, Set |
| 1 | 0 | 0, Reset |
| 0 | 0 | 부정/금지 |

플립플롭 진리표:

| 종류 | 입력 | Q 다음 상태 | 핵심 |
|---|---|---|---|
| D | D=0 | 0 | 입력을 그대로 저장 |
| D | D=1 | 1 | `Q+ = D` |
| JK | J=0, K=0 | 유지 | SR의 금지 상태 해결 |
| JK | J=0, K=1 | 0 | Reset |
| JK | J=1, K=0 | 1 | Set |
| JK | J=1, K=1 | 반전 | Toggle |
| T | T=0 | 유지 | Toggle 플립플롭 |
| T | T=1 | 반전 | `Q+ = T xor Q` |

특성식:
- SR: `Q+ = S + R'Q`, 단 `S = R = 1` 금지
- D: `Q+ = D`
- JK: `Q+ = JQ' + K'Q`
- T: `Q+ = TQ' + T'Q = T xor Q`

비동기 입력:
- Preset/Set과 Clear/Reset은 클록보다 우선한다.
- 비동기 입력은 클록 에지와 무관하게 즉시 출력을 바꾼다.
